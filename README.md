# قصص الأنبياء المسموعة — تطبيق «أثره الطيب»

ملفات صوت قصص الأنبياء اللي بيشغّلها تطبيق «أثره الطيب»: ملف لكل نبي (`01.m4a` … `25.m4a`) في الـ Releases.

- **السرد:** صوت مولَّد بموديل [NAMAA-Egyptian-TTS](https://huggingface.co/NAMAA-Space/NAMAA-Egyptian-TTS) (NAMAA Community، رخصة MIT) المبني على Chatterbox من Resemble AI.
- **الآيات:** تلاوة الشيخ محمود خليل الحصري (مرتل)، من ملفات QuranicAudio / Quran.com.
- **النص:** قصص الأنبياء من القرآن الكريم والسنة الصحيحة كما في التطبيق.

صدقة جارية على روح الحاج مطاوع رحمه الله.
